# Template skills (drafts)

Skill texts for a public Grok Bot template that uses this connector. A template
can carry skills, memories, routines and marketplace plugins, but not code, so
`getting-started` installs the connector from this repo on the new owner's box.

| Skill | Purpose |
|-------|---------|
| getting-started.md | First conversation: install, sign-ins, register, alerts, /changem, decision desk, end-to-end test |
| changem.md | /changem: pick the bot's default model and show it in the bot's name |
| model-handoff.md | Hand a task to Codex/Claude and report back (checked summary + verbatim reply) |
| decision-desk.md | One queue of everything needing the owner, shown one item at a time |

`bot/model-connector/SKILL.md` (repo root) is an optional, more technical
reference skill for the connector's tool contract.
